## ⚙️ ОПТИМИЗАЦИЯ ДЛЯ IPHONE 12

### Настройки графики:
- **Render Distance:** 16-24 чанка
- **Graphics:** Fancy (можно Beautiful)
- **Smooth Lighting:** ON
- **Particles:** Medium
- **Clouds:** OFF (для +10 FPS)

### Команды:
- `/dh set 16` — уменьшить дальность (если лаги)
- `/dh set 42` — максимальная дальность
- `/rad info` — проверить радиацию
- `/rad help` — помощь по радиации
