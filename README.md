## 🎮 **Команды**

| Команда | Описание |
|---------|----------|
| `/radiation` | Показать уровень радиации |
| `/radiation set <level>` | Установить уровень (0-100) |
| `/geiger` | Счётчик Гейгера |
| `/fallout [type]` | Создать зону (atomic, thermonuclear, apocalypse, doomsday) |
| `/clearzones` | Очистить все зоны |
| `/bombinfo <type>` | Информация о бомбе |

---

## ☢️ **Как работает**

1. **Взрыв бомбы** → создаётся зона радиации
2. **Попадание в зону** → таймер 30 секунд
3. **Не успел сбежать** → радиация растёт → урон → смерть
4. **Успел сбежать** → радиация спадает → выжил
