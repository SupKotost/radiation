# ☢️ Radiation v2 - HARDCORE EDITION

**Behavior Pack для Minecraft Bedrock Edition**

## 📦 Структура:

```
radiation_bp/
├── manifest.json
├── pack_icon.png
└── scripts/
    ├── main.js
    ├── RadiationManager.js
    ├── HUD.js
    ├── Commands.js
    ├── BoGCompatibility.js
    └── RadioactiveBlockComponent.js
```

## 🚀 Установка:

1. Скачай все файлы из этой папки
2. Положи в одну папку radiation_bp/
3. Запакуй в .zip → переименуй в .mcpack
4. Открой в Minecraft Bedrock
5. Включи Script API + Behavior Pack

## 🎮 Команды:

- `/radiation` - Показать уровень радиации
- `/geiger` - Счётчик Гейгера
- `/fallout [type]` - Создать зону
- `/clearzones` - Очистить все зоны
